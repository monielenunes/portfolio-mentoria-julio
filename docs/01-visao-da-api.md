# Visão da API

A MimoRH API apoia o RH no cadastro de colaboradores, datas especiais, presentes e respectivos envios. É uma API REST educacional, com persistência em arquivos JSON locais e sem integrações externas.

Use `npm start` e acesse `http://localhost:3000/api/health`. Para demonstração administrativa, use `admin@mimorh.local` / `Admin123!`.
